# 📚 DOM Manipulation Exercises - Complete Package

## 🎯 Overview

This repository contains a comprehensive collection of DOM manipulation exercises organized by difficulty level and topic. All exercises include **hidden solutions** with hints to encourage learning.

## 📂 File Structure

### 1. **README.md** - Beginner to Intermediate (Levels 1-12)
Main exercise file covering fundamental DOM manipulation concepts:

**Levels:**
- **Level 1-4:** Element Selection (ID, Class, querySelector)
- **Level 5-7:** Content and DOM Modification (textContent, innerHTML, createElement)
- **Level 8-12:** Template Literals and HTML Template Elements

**Key Topics:**
- Selecting elements by ID, class, and CSS selectors
- Changing text content and HTML
- Styling elements with classList and inline styles
- Working with attributes and data attributes
- Creating and deleting elements
- Event handling (click, input, mouse events)
- Dynamic element addition
- Template literals for string interpolation
- HTML template elements for component creation
- Mini projects (Todo list, card layouts, search/filter)

**Features:**
- 48+ exercises
- Progressive difficulty
- Collapsible solutions with `<details>` tags
- Hints before each solution
- Real-world examples
